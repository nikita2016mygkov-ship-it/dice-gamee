Инструкция по запуску игры в кости
ШАГ 1: Установить VS Code
Скачай редактор кода с официального сайта и установи его на компьютер.

ШАГ 2: Установить Python
Скачай Python с официального сайта. Важно! При установке обязательно поставь галочку "Add Python to PATH" в самом начале.

ШАГ 3: Создать папку для проекта
Создай новую папку на рабочем столе. В VS Code открой эту папку через File → Open Folder.

ШАГ 4: Создать файл с игрой
В VS Code создай новый файл и сохрани его под именем game.py.

ШАГ 5: Скопировать код игры
Выдели весь код из инструкции, скопируй его и вставь в файл game.py, затем сохрани изменения.

ШАГ 6: Запустить игру
Нажми на треугольник ▶️ в правом верхнем углу VS Code или клавишу F5. Внизу откроется терминал с меню игры.

ШАГ 7: Если ничего не работает
"Python не найден" → переустанови Python с галочкой "Add to PATH"

Ничего не происходит → закрой и открой VS Code заново

Ошибка с кодировкой → сохрани файл в кодировке UTF-8

Терминал закрывается → в коде уже есть input(), он задержит окно

ШАГ 8: Сохранить на GitHub (для сдачи проекта)
Зарегистрируйся на GitHub

Создай новый репозиторий с названием dice-game

В VS Code открой терминал и настрой Git (команды из инструкции)

При входе используй токен вместо пароля (создаётся в настройках GitHub)

ШАГ 9: Проверь загрузку
Зайди на свой GitHub и убедись, что файл game.py появился в репозитор
